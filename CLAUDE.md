# Pocket Pirates (the game is called HOIST): notes for Claude

A low-poly, PS1-style pirate exploration game (Three.js + Vite) that is played as a cosy Caribbean game and turns,
unexpectedly, into cosmic horror. Everything is procedural: no image or model files.

## Read these first, in this order
1. `docs/CANON.md`: what is true in the story, every dated decision, what is still open. One page.
2. `docs/RULES.md`: the standing rules every change must keep (story, interface, look, sound, code, working).
3. `docs/AREAS.md`: which docs and files belong to design, gameplay and audio. Load only your area's docs; read another
   area only when the task needs it. Specialist agents live in `.claude/agents/` (`design`, `gameplay`, `audio`): use one when
   a task sits inside one area; the main session coordinates tasks that cross areas.
4. `ARCHITECTURE_AND_LORE_GUIDE.md` (root): the code map and contracts, the look in numbers, how the lore is carried by the
   mechanics, the task backlog and the working protocol. It ranks below the three above; its evidence is `docs/AUDIT_2026-11-14.md`.

## Always
- Horror is implied, never explained. Keep the HUD wordless and the writing short. Never resolve a storyline casually.
- Only the owner decides canon. If `CANON.md` section 8 lists it as open, ask; never fill it in.
- When something lands: add to `docs/PROGRESS.md`; a decision goes in `docs/CANON.md` with its date; a new rule goes in `docs/RULES.md`.
- When player-facing text changes: `python3 scripts/story_export.py` (rebuilds `docs/STORY_MASTER.txt` from the code).
- The demo build (`window.__BUILD === 'demo'`) is a different game: no dread, nothing from after the hut. Check for leaks.

## How the game is now (2026-11-27; the code is the truth, this is the short list of things older docs may still get wrong)
- **One world per seed, and the seed is 1337** unless `?seed=` is given: every new game sails the same map. The islands are generated by
  code from the seed; Tama, the starter cells, the hand-made places (`landmarks.js`), Haven Hesk and its islet, the six named wrecks
  (`systems/wrecks.js`) and the three shallow groups (`systems/shallows.js`) are fixed or placed by the seed in their area.
- **No tides, no tide clock.** `systems/calendar.js lowWater()`: the sea draws back only on the nights round a new or a full moon (Bell
  Below, Tide Rocks, Throwers' Wreck, Sunken Street, Drowned planks); everything else that used to wait on the tide is always open.
  `waterAt()` is the level for the places that show it. Test with `?lowwater=1` or the dev panel's "Next low water night".
- **Reefs are off** (`core/config.js REEFS_ON = false`): no coral heads, no Reef white water, and no Drowned belt or race. Sandbanks are
  on (`SANDBANKS_ON`).
- **The Halved Isle's fog closes in** (`fogbank.js`, `places.js`): no shape in the world; the scene haze thickens over a long ramp from 220
  outside the bank (R 210) and a fine mist lies round the ship. Its colour follows the daylight. Deep in it you see about 50
  (`main.js BANK_FAR`) even with the lens lantern; the sky goes overcast and fogged, and islands and ships beyond the fog are not drawn.
- **Haven Hesk** (`systems/foghaven.js`): the fog harbour, full game only; `?foghaven=abandoned|flicker|stirring|bustling|forsaken`.
  It lies across the bank from the Halved Isle (about 150 apart); Hesper's light is on its own rock, Hesk Light (`world.js
  heskLight`, a tower like the one in the film The Lighthouse, her rowing boat). It is rebuilt with food and hands (crew who stay); until it is back only Hesper is there (`havenOpen`: market and errands at
  stirring, tavern, shipwright, passengers and local life at bustling).
- **The Gull's lanterns** (`ship.js sternLamp`, `bowLamp`): iron-framed lanterns at both ends.
- **Artbooks** (`docs/artbook/`): `hoist_artbook.html` (the look, technical) and `hoist_beyond_the_fair_winds.html` (a read that sells
  the game). Rebuilt by hand from captures; refresh them when the look changes a lot.

## Working
- Dev server: `npx vite --port 5173 --host 127.0.0.1`; build: `npx vite build`.
- Test headless with Playwright (Chromium at `/opt/pw-browsers/chromium`, swiftshader flags) and the
  `window.__game` hook plus URL flags (`autostart=1&fresh=1&shot=1&nomate=1&dread=&time=&x=&z=`). It runs at about a tenth
  of real speed: wait on game state, not on the clock, and do not judge feel or sound from it.
- After a change: build, `npm run smoke` (about 3 minutes), screenshot what changed, commit and push. Say what was verified and what was not.
- The standalone app (`electron/`, Electron) is built only when the owner asks (RULES 38a).
- Single-file games (`npx vite build && python3 scripts/single.py`: `pocket-pirates-demo.html` for sharing,
  `pocket-pirates-demo-silent.html`, `pocket-pirates-dev.html` with mixer F8, Sound Studio F9, test tools; `pocket-pirates-full.html` the whole game for playtesting,
  no test tools, URL flags ignored; `python3 scripts/single.py full` builds just that one) only when asked.
  `pocket-pirates-mobile.html` (`single.py mobile`) is the full game for phones: landscape only (a turn-the-phone card in portrait),
  the touch pad always on, extra buttons for the log (M), oars (G) and shot (B), pinch to zoom, a smaller HUD; Mara drops the key letters.
