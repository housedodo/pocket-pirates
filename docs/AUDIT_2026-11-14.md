# Audit, 2026-11-14

The evidence behind `ARCHITECTURE_AND_LORE_GUIDE.md`. Four read-only passes over the code and docs: architecture and systems;
look, interface and sound; lore; how the mechanics carry the lore. Nothing in the game was changed.

**How far to trust it.** "Checked" means the line was read in the code (or the command was run). "Reported" means one pass
found it by reading and it was not run. Nothing here was play-tested; feel and sound cannot be judged headless. Line numbers
are as of commit `380b747` and will drift.

## 1. Technical health

### In short
The layering is sound: one import cycle (the documented `world -> harbourlife -> jobs -> world`), nothing imports `main.js`,
all 55 `G` getters are used, all 51 top-level state keys are saved. `npx vite build` passes in under a second (104 modules, one
1.4 MB chunk, 456 KB gzipped). The weak points are the size and line length of `main.js` and `world.js`, goal indices as bare
numbers, the demo gates, wall-clock timers, and the absence of any automated check that runs without a person.
