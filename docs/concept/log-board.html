The log board

Riddles, rumours, chart notes, bottles and letters all land in the captain's log as cards. This is the board where you pin them, tie them together and say where you think they point. The game never says if you are right: the answer is only in sailing there. Wrong guesses cost time and, sometimes, a false rumour the Lady counts.

A · The board. Every clue is a paper card pinned on cork: riddles in plain paper, rumours in grey, bottles in green, letters in cream. You drag cards where you like and tie them with red string (sure) or dashed blue string (a doubt). The pencil notes at the bottom are yours alone. Nothing is checked: no ticks, no "solved". Cards the game knows to be false look exactly like the rest.

The pencil only reminds you. It does not set a course, and it never turns green.

B · Putting a clue on the map. "On the map" opens the chart. You circle the island you think a riddle points to in dashed pencil; two guesses can sit side by side, the weaker one fainter. It is a memory aid and nothing more: no marker, no route. The first riddle is the only one that is marked for you.
